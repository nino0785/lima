# Lima Store — Site

Site em HTML/CSS/JS puro. Para ver, basta abrir o `index.html` no navegador (não precisa instalar nada).

## Estrutura

```
lima-store/
├── index.html            → todo o conteúdo da página (textos e seções)
├── css/
│   └── style.css         → estilos: cores base, fontes dos títulos, animação e detalhes
├── js/
│   ├── tailwind-config.js → paleta de cores e fontes do Tailwind
│   └── main.js           → menu mobile e ícones
└── images/               → fotos do site (hero e coleções)
```

## Onde editar

- **Textos e links** → `index.html` (WhatsApp, endereço, Instagram e seções)
- **Cores e animações extras** → `css/style.css`
- **Cores do Tailwind** (fundo, destaque dourado etc.) → `js/tailwind-config.js`
- **Comportamentos** (menu, ícones) → `js/main.js`
